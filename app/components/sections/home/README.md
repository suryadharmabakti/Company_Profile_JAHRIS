# Section halaman utama

- `hero-section.tsx` — bagian pembuka halaman.
- `features-section.tsx` — fitur utama dan alur operasional HR.
- `interface-section.tsx` — tampilan antarmuka produk.
- `pricing-section.tsx` — paket harga.
- `cta-section.tsx` — ajakan kontak dan visual perangkat.
- `data.ts` — data modul serta paket harga.
- `footer.tsx` — footer halaman.

`app/page.tsx` hanya menyusun urutan section-section ini.
